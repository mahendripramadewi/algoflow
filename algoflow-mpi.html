02 · Materi — 1/7

Apa itu Algoritma?

Algoritma adalah urutan langkah-langkah logis dan sistematis yang disusun untuk menyelesaikan suatu masalah atau mencapai tujuan tertentu, dalam jumlah langkah yang terbatas (finite).

Tepat

Setiap langkah harus jelas dan tidak menimbulkan makna ganda (ambigu).

Berurutan

Langkah dikerjakan sesuai urutan logis, dari awal hingga akhir.

Berhenti

Algoritma harus berakhir setelah sejumlah langkah tertentu — tidak berjalan selamanya.

💡 Analogi sederhana: resep membuat mi instan adalah sebuah algoritma — didihkan air, masukkan mi, tunggu 3 menit, tiriskan, campur bumbu, sajikan. Urutannya jelas, logis, dan pasti berhenti.

02 · Materi — 2/7

Cara #1 — Kalimat Deskriptif

Algoritma ditulis menggunakan kalimat/bahasa sehari-hari (bahasa natural) secara berurutan.

Contoh: Algoritma Menentukan Bilangan Genap/Ganjil
  1. Mulai.
  2. Masukkan sebuah bilangan bulat N.
  3. Bagi N dengan 2, lalu perhatikan sisa baginya.
  4. Jika sisa baginya sama dengan 0, maka N adalah bilangan genap.
  5. Jika tidak, maka N adalah bilangan ganjil.
  6. Tampilkan hasilnya.
  7. Selesai.

✅ Kelebihan: mudah dipahami siapa saja, tanpa perlu tahu simbol atau sintaks tertentu.
⚠️ Kekurangan: bisa jadi panjang dan kurang presisi untuk algoritma yang kompleks.

02 · Materi — 4/7

Cara #3 — Pseudocode

Algoritma ditulis menyerupai kode program, tetapi tidak terikat pada aturan (sintaks) bahasa pemrograman tertentu.

Contoh: Genap/Ganjil dalam Pseudocode
MULAI
  Input N
  JIKA N mod 2 = 0 MAKA
      Output "Genap"
  JIKA TIDAK
      Output "Ganjil"
  AKHIR JIKA
SELESAI

💡 Pseudocode adalah "jembatan" antara bahasa manusia dan bahasa pemrograman sungguhan (seperti Python, Java, atau C++) — lebih presisi dari kalimat deskriptif, tapi lebih fleksibel dari kode asli.

02 · Materi — 5/7

Varian & Invarian dalam Perulangan

Dua konsep penting untuk memastikan sebuah loop (perulangan) bekerja dengan benar dan pasti berhenti.

Varian (Variant)

Ekspresi/nilai yang berubah secara konsisten (biasanya menurun) di setiap iterasi, dan menuju suatu batas berhenti.

🎯 Fungsinya: menjamin loop pasti berakhir — mencegah perulangan tak terhingga (infinite loop).

Invarian (Invariant)

Kondisi atau pernyataan yang selalu bernilai benar di awal setiap iterasi, sebelum maupun sesudah loop berjalan.

🎯 Fungsinya: membuktikan bahwa algoritma berjalan benar — hasil akhirnya sesuai yang diharapkan.

🧠 Ingat: Varian menjawab pertanyaan "kapan loop ini berhenti?", sedangkan Invarian menjawab pertanyaan "apakah loop ini selalu bekerja dengan benar?"

02 · Materi — 6/7

Studi Kasus: Algoritma Faktorial (N!)

Mari telusuri varian dan invarian pada algoritma menghitung faktorial dari N = 4.

MULAI
  Input N
  hasil ← 1
  i ← 1
  SELAMA i <= N LAKUKAN
      hasil ← hasil * i
      i ← i + 1
  AKHIR SELAMA
  Output hasil
SELESAI
Tabel Lacak (Trace Table) untuk N = 4
IterasiihasilInvarian: hasil = (i−1)!Varian: N − i
Awal111 = 0! ✓3
1211 = 1! ✓2
2322 = 2! ✓1
3466 = 3! ✓0
4 (berhenti)52424 = 4! ✓−1 → loop berhenti

📌 Varian-nya adalah nilai (N − i) yang terus berkurang tiap iterasi menuju 0 — ini menjamin loop pasti berhenti.
📌 Invarian-nya adalah pernyataan hasil = (i−1)! yang selalu benar di setiap awal iterasi — ini membuktikan hasil akhirnya pasti benar.
